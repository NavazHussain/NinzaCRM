Overview
Automation testing project for the NinzaCRM web application 
using Selenium WebDriver with Java.

Tech Stack
- Selenium WebDriver
- Java
- TestNG
- Page Object Model (POM)
- Data Driven Testing (DDT) – Apache POI
- Maven
- Jenkins (CI/CD)
- GitHub

Test Suites
- Smoke Testing – SmokeSuite.xml
- Regression Testing – RegressionSuite.xml
- Cross Browser Testing – CrossBrowserSuit.xml
- Batch Testing – BatchSuite.xml
- Distributed Testing – DistributedSuite.xml

Features
- Automated login and customer management modules
- Cross-browser testing on Chrome, Firefox, and Edge
- Data Driven Testing using Excel files via Apache POI
- Screenshot capture on test execution
- Integrated with Jenkins for automated build and test execution

How to Run
1. Clone the repository
2. Open in Eclipse or IntelliJ
3. Run using TestNG suite XML files or Maven commands
